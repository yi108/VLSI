# VLSI System Design 上機考 — 考題預測與參考程式碼

根據講義（01b 資料型態、02a/02b Sequential Blocks & FSM & Synthesis）與 HW1（ALU/FPU）、HW2（5-stage CPU）的範圍推測。
上機考最可能考的是 **FSM（Moore/Mealy）**、**Controller + Datapath（加密單元型題目）**、**ALU 解碼**、以及 **always_comb / always_ff 正確寫法**。

## 考點機率分析

| 排名 | 題型 | 理由 |
|---|---|---|
| ★★★★★ | Moore / Mealy FSM（序列偵測器，補完 case） | 02a 講義直接留白 `// fill the rest of the code`，標準出題手法 |
| ★★★★★ | 加密單元 Controller（INIT/READ/WRITE/FINAL） | 02b 完整 reference code 只給部分，上機考常直接改規格重出 |
| ★★★★ | 3-block FSM（always_ff + always_comb + 輸出暫存器） | 02a 專頁強調，SystemVerilog 風格重點 |
| ★★★★ | ALU 指令解碼（RV32I 子集 + CLZ/CPOP/SADD8 等） | HW1 Prob.A 的簡化版很適合 2 小時上機 |
| ★★★ | 計數器 / 除頻器 / 移位暫存器 / DFF 變形 | 基本功，常當第一題 |
| ★★★ | FPU MIN/MAX 比較器（IEEE-754） | HW1 Prob.B 中最可能在考場內完成的部分 |
| ★★ | 補 testbench（clock/reset/pattern 比對） | HW 環境都用 VCS + pattern，有可能給 DUT 要你寫 TB |

觀念陷阱（會藏在題目裡）：
- 組合邏輯用 `=`（blocking）、時序邏輯用 `<=`（non-blocking）
- `case` 要有 `default` 或每個分支先給預設值，否則合成出 latch
- `always_ff` 只能有一個 event control；LHS 不可被其他 process 寫
- `always_comb` 在 time 0 會自動執行一次、不可含 `#delay` / event control
- 非同步 reset 寫法：`always_ff @(posedge clk or posedge rst)`（或 `negedge rst_n`）
- enum 預設 base type 是 `int`（2-state）→ 建議 `enum logic [n:0] {...}`

## 題 1：Moore 序列偵測 FSM（講義 02a p.18–21 的補完版）

**題目**：4 個狀態 S0~S3（2-bit 編碼），每個 clock 讀入 Din 換狀態，reset 回 S0。
Qout 只由狀態決定：S0=0, S1=1, S2=1, S3=0。

```systemverilog
`timescale 1ns/10ps
module moore (
    output logic       Qout,
    input  logic       clk, rst, Din
);
    parameter [1:0] S0 = 2'b00, S1 = 2'b01, S2 = 2'b10, S3 = 2'b11;
    logic [1:0] CS, NS;

    // state register
    always_ff @(posedge clk or posedge rst) begin
        if (rst) CS <= S0;
        else     CS <= NS;
    end

    // next-state logic (combinational)
    always_comb begin
        NS = CS;                      // default，避免 latch
        case (CS)
            S0: NS = (Din) ? S2 : S0;
            S1: NS = (Din) ? S2 : S0;
            S2: NS = (Din) ? S3 : S1;
            S3: NS = (Din) ? S3 : S1;
            default: NS = S0;
        endcase
    end

    // Moore output：只看狀態
    always_comb begin
        case (CS)
            S1, S2:  Qout = 1'b1;
            default: Qout = 1'b0;
        endcase
    end
endmodule
```

> 轉移表若題目不同，只要改 `case` 內容；骨架（三段式）不變。

## 題 2：Mealy FSM（講義 02a p.22–23 的補完版）

**題目**：狀態 S0=00, S1=01, S2=11。
轉移/輸出：S0: 0/0→S0, 1/0→S1；S1: 0/0→S2, 1/0→S1；S2: 0/0→S0, 1/1→S1。

```systemverilog
module mealy (
    output logic Qout,
    input  logic clk, rst, Din
);
    parameter [1:0] S0 = 2'b00, S1 = 2'b01, S2 = 2'b11;
    logic [1:0] CS, NS;

    always_ff @(posedge clk or posedge rst) begin
        if (rst) CS <= S0;
        else     CS <= NS;
    end

    // Mealy：輸出同時取決於狀態與輸入
    always_comb begin
        NS   = S0;
        Qout = 1'b0;
        case (CS)
            S0: begin
                if (Din) begin NS = S1; Qout = 1'b0; end
                else     begin NS = S0; Qout = 1'b0; end
            end
            S1: begin
                if (Din) begin NS = S1; Qout = 1'b0; end
                else     begin NS = S2; Qout = 1'b0; end
            end
            S2: begin
                if (Din) begin NS = S1; Qout = 1'b1; end  // 1/1
                else     begin NS = S0; Qout = 1'b0; end
            end
            default: begin NS = S0; Qout = 1'b0; end
        endcase
    end
endmodule
```

## 題 3：加密單元 Controller（02b 的核心範例，最高風險題）

**題目**：LM2[i] = LM1[i] ^ LM2[i]。FSM：INIT → READ → WRITE →（LM2_A == 16'hffff 時）→ FINAL。
READ 時 LM1_OE=LM2_OE=1；WRITE 時 LM1_OE=LM2_OE=LM2_WE=1 並且位址 +1；FINAL 時 done=1。

```systemverilog
module Controller (
    input  logic        clk, rst,
    output logic [13:0] LM1_A,
    output logic        LM1_OE,
    output logic [15:0] LM2_A,
    output logic        LM2_WE, LM2_OE,
    output logic        done
);
    parameter [1:0] INIT  = 2'b00,
                    READ  = 2'b01,
                    WRITE = 2'b10,
                    FINAL = 2'b11;

    logic [1:0] cstate, nstate;

    // 1) state register
    always_ff @(posedge clk or posedge rst) begin
        if (rst) cstate <= INIT;
        else     cstate <= nstate;
    end

    // 2) next-state logic
    always_comb begin
        case (cstate)
            INIT :  nstate = READ;
            READ :  nstate = WRITE;
            WRITE:  nstate = (LM2_A == 16'hffff) ? FINAL : READ;
            FINAL:  nstate = FINAL;
            default:nstate = INIT;
        endcase
    end

    // 3) address counter（時序）
    always_ff @(posedge clk or posedge rst) begin
        if (rst)                    LM2_A <= 16'd0;
        else if (cstate == WRITE)   LM2_A <= LM2_A + 1'b1;
    end

    // 4) FSM 輸出（組合，先給預設值避免 latch）
    always_comb begin
        LM1_A  = LM2_A[15:2];   // 128x128 mask 對 256x256 image 的映射：{LM2_A[15:9], LM2_A[7:1]} 視題目而定
        LM1_OE = 1'b0;
        LM2_WE = 1'b0;
        LM2_OE = 1'b0;
        done   = 1'b0;
        case (cstate)
            READ:  begin LM1_OE = 1'b1; LM2_OE = 1'b1; end
            WRITE: begin LM1_OE = 1'b1; LM2_OE = 1'b1; LM2_WE = 1'b1; end
            FINAL: begin done = 1'b1; end
            default: ;
        endcase
    end
endmodule

// Datapath 計算單元
module ComputationUnit (
    input  logic [23:0] color_in1, color_in2,
    output logic [23:0] color_out
);
    always_comb color_out = color_in1 ^ color_in2;
endmodule
```

> 講義原版 LM1_A = {LM2_A[15:9], LM2_A[7:1]}（mask 128x128 重複貼到 256x256）。考試若改規格（例如改成加法、改記憶體大小），FSM 骨架照抄、只改輸出表和結束條件。

## 題 4：3-Block FSM 標準範本（紅綠燈，one-hot enum）

```systemverilog
module traffic_light (
    input  logic clk, resetN, sensor,
    input  logic [3:0] green_downcnt,
    output logic red_light, green_light, yellow_light
);
    enum logic [2:0] {RED    = 3'b001,
                      GREEN  = 3'b010,
                      YELLOW = 3'b100} State, Next;

    // Block 1: state register
    always_ff @(posedge clk, negedge resetN)
        if (!resetN) State <= RED;
        else         State <= Next;

    // Block 2: next-state logic
    always_comb begin
        Next = State;                      // default 防 latch
        unique case (State)
            RED:    if (sensor)              Next = GREEN;
            GREEN:  if (green_downcnt == 0)  Next = YELLOW;
            YELLOW:                          Next = RED;
        endcase
    end

    // Block 3: output logic
    always_comb begin
        {green_light, yellow_light, red_light} = 3'b000;
        unique case (State)
            RED:    red_light    = 1'b1;
            GREEN:  green_light  = 1'b1;
            YELLOW: yellow_light = 1'b1;
        endcase
    end
endmodule
```

若題目要求「輸出經暫存器打一拍（registered output）」，把 Block 3 改成：

```systemverilog
always_ff @(posedge clk, negedge resetN) begin
    if (!resetN) {green_light, yellow_light, red_light} <= 3'b000;
    else begin
        {green_light, yellow_light, red_light} <= 3'b000;
        unique case (Next)                 // 用 next_state 看齊下一拍
            RED:    red_light    <= 1'b1;
            GREEN:  green_light  <= 1'b1;
            YELLOW: yellow_light <= 1'b1;
        endcase
    end
end
```

## 題 5：簡化版 ALU（HW1 Prob.A 考場版）

**題目**：依 instruction_i 的 opcode/funct3/funct7 解碼，輸出 result_o。

```systemverilog
module ALU (
    input  logic [31:0] instruction_i,
    input  logic [31:0] src_A_i, src_B_i,
    output logic [31:0] result_o
);
    logic [6:0] opcode, funct7;
    logic [2:0] funct3;
    logic [4:0] shamt;

    assign opcode = instruction_i[6:0];
    assign funct3 = instruction_i[14:12];
    assign funct7 = instruction_i[31:25];
    assign shamt  = src_B_i[4:0];

    // CLZ / CPOP 用 function
    function automatic logic [31:0] clz(input logic [31:0] x);
        clz = 32;
        for (int i = 31; i >= 0; i--)
            if (x[i]) begin clz = 31 - i; break; end
    endfunction

    function automatic logic [31:0] cpop(input logic [31:0] x);
        cpop = '0;
        foreach (x[i]) cpop += x[i];
    endfunction

    // 8-bit 飽和加法（SADD8 的一個 lane）
    function automatic logic [7:0] sat8(input logic signed [8:0] s);
        if      (s >  9'sd127) sat8 = 8'd127;
        else if (s < -9'sd128) sat8 = 8'h80;
        else                   sat8 = s[7:0];
    endfunction

    logic signed [63:0] mul_ss;
    assign mul_ss = $signed(src_A_i) * $signed(src_B_i);

    always_comb begin
        result_o = 32'd0;
        case (opcode)
            7'b0110011: begin   // R-type / M / 部分 B-ext
                unique case ({funct7, funct3})
                    {7'b0000000,3'b000}: result_o = src_A_i + src_B_i;            // ADD
                    {7'b0100000,3'b000}: result_o = src_A_i - src_B_i;            // SUB
                    {7'b0000000,3'b001}: result_o = src_A_i << shamt;             // SLL
                    {7'b0000000,3'b010}: result_o = ($signed(src_A_i) < $signed(src_B_i)); // SLT
                    {7'b0000000,3'b011}: result_o = (src_A_i < src_B_i);          // SLTU
                    {7'b0000000,3'b100}: result_o = src_A_i ^ src_B_i;            // XOR
                    {7'b0000000,3'b101}: result_o = src_A_i >> shamt;             // SRL
                    {7'b0100000,3'b101}: result_o = $signed(src_A_i) >>> shamt;   // SRA
                    {7'b0000000,3'b110}: result_o = src_A_i | src_B_i;            // OR
                    {7'b0000000,3'b111}: result_o = src_A_i & src_B_i;            // AND
                    {7'b0000001,3'b000}: result_o = mul_ss[31:0];                 // MUL
                    {7'b0000001,3'b001}: result_o = mul_ss[63:32];                // MULH
                    // RV32B（R-type 部分）
                    {7'b0110000,3'b001}: result_o = (src_A_i << shamt) | (src_A_i >> (32-shamt)); // ROL
                    {7'b0110000,3'b101}: result_o = (src_A_i >> shamt) | (src_A_i << (32-shamt)); // ROR
                    {7'b0000101,3'b100}: result_o = ($signed(src_A_i) < $signed(src_B_i)) ? src_A_i : src_B_i; // MIN
                    {7'b0000101,3'b110}: result_o = ($signed(src_A_i) > $signed(src_B_i)) ? src_A_i : src_B_i; // MAX
                    {7'b0010100,3'b001}: result_o = src_A_i |  (32'd1 << shamt);  // BSET
                    {7'b0100100,3'b001}: result_o = src_A_i & ~(32'd1 << shamt);  // BCLR
                    {7'b0100100,3'b101}: result_o = (src_A_i >> shamt) & 32'd1;   // BEXT
                    default: result_o = 32'd0;
                endcase
            end
            7'b0010011: begin   // CLZ/CTZ/CPOP（I-type 編碼空間）
                unique case (instruction_i[24:20])
                    5'b00000: result_o = clz(src_A_i);
                    5'b00010: result_o = cpop(src_A_i);
                    default:  result_o = 32'd0;
                endcase
            end
            7'b0001011: begin   // DSP custom
                unique case (funct3)
                    3'b000: begin   // DOTP4
                        logic signed [31:0] acc;
                        acc = '0;
                        for (int i = 0; i < 4; i++)
                            acc += $signed(src_A_i[8*i +: 8]) * $signed(src_B_i[8*i +: 8]);
                        result_o = acc;
                    end
                    3'b001: for (int i = 0; i < 4; i++)   // SADD8
                        result_o[8*i +: 8] = sat8($signed({src_A_i[8*i+7], src_A_i[8*i +: 8]})
                                                + $signed({src_B_i[8*i+7], src_B_i[8*i +: 8]}));
                    3'b010: for (int i = 0; i < 4; i++)   // SSUB8
                        result_o[8*i +: 8] = sat8($signed({src_A_i[8*i+7], src_A_i[8*i +: 8]})
                                                - $signed({src_B_i[8*i+7], src_B_i[8*i +: 8]}));
                    3'b011: result_o = (src_A_i == 32'h8000_0000) ? 32'h7FFF_FFFF :  // ABS
                                       ($signed(src_A_i) < 0) ? -$signed(src_A_i) : src_A_i;
                    3'b100: result_o = ($signed(src_A_i) >  127) ? 32'd127 :          // CLIP8
                                       ($signed(src_A_i) < -128) ? -32'd128 : src_A_i; // sign-extended
                    default: result_o = 32'd0;
                endcase
            end
            default: result_o = 32'd0;
        endcase
    end
endmodule
```

## 題 6：IEEE-754 MIN/MAX 比較器（HW1 Prob.B 的可考部分）

**關鍵**：浮點不能直接用無號比較 —— 符號不同時負數小；同為負時 magnitude 大的反而小；注意 +0 / −0 視為相等。

```systemverilog
module fpu_cmp (
    input  logic [31:0] ai, bi,
    input  logic        sel_max,        // 0: min, 1: max
    output logic [31:0] co
);
    logic sa, sb, a_lt_b, both_zero;
    assign sa = ai[31];
    assign sb = bi[31];
    assign both_zero = (ai[30:0] == 31'd0) && (bi[30:0] == 31'd0);

    always_comb begin
        if (both_zero)        a_lt_b = sa & ~sb;          // -0 < +0（依題目規定）
        else if (sa != sb)    a_lt_b = sa;                // 負的小
        else if (!sa)         a_lt_b = (ai[30:0] < bi[30:0]);
        else                  a_lt_b = (ai[30:0] > bi[30:0]); // 都是負：絕對值大的小
    end

    assign co = (a_lt_b ^ sel_max) ? ai : bi;
endmodule
```

### FPU ADD/SUB 流程（若考簡答或框架填空，背這個順序）
1. **Unpack**：拆 S/E/F，特殊值判斷（E=255 且 F≠0 → NaN；E=255 且 F=0 → Inf；E=0 F=0 → Zero）
2. **Align**：ΔE = |Ea − Eb|，小 exponent 的 mantissa 右移 ΔE，移出去的位進 G/R/S
3. **Add/Sub**：依符號與指令做 mantissa 加減
4. **Normalize**：有 carry → 右移 1、E+1；有 cancellation → 左移 k、E−k
5. **Round（round-to-nearest-even）**：GRS=0xx 捨去；GRS=110/101/111 進位；GRS=100 看 LSB（LSB=1 進位、=0 捨去）
6. **Pack**：組回 {S, E[7:0], F[22:0]}；x−x 得 +0（32'h00000000）

## 題 7：基本時序電路（熱身題）

```systemverilog
// (a) 帶同步 set/非同步 reset 的 DFF
module dff_sr (
    output logic q,
    input  logic d, set, rst_n, clk
);
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n)    q <= 1'b0;   // 非同步清 0
        else if (set)  q <= 1'b1;   // 同步 set
        else           q <= d;
    end
endmodule

// (b) mod-N 計數器 + 除頻（例：50% duty 除 10）
module clk_div10 (
    input  logic clk, rst_n,
    output logic clk_o
);
    logic [2:0] cnt;
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n)            begin cnt <= '0; clk_o <= 1'b0; end
        else if (cnt == 3'd4)  begin cnt <= '0; clk_o <= ~clk_o; end
        else                   cnt <= cnt + 1'b1;
    end
endmodule

// (c) 8-bit 可載入左右移位暫存器
module shift_reg (
    input  logic       clk, rst_n, load,
    input  logic [1:0] mode,        // 00 hold, 01 left, 10 right
    input  logic [7:0] din,
    input  logic       sin,
    output logic [7:0] q
);
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n)      q <= '0;
        else if (load)   q <= din;
        else case (mode)
            2'b01:  q <= {q[6:0], sin};
            2'b10:  q <= {sin, q[7:1]};
            default: q <= q;
        endcase
    end
endmodule
```

## 題 8：Testbench 範本（VCS 環境）

```systemverilog
`timescale 1ns/10ps
module ALU_tb;
    parameter CYCLE = 10;
    logic        clk, rst;
    logic [31:0] instruction, src_A, src_B;
    logic [31:0] result, golden;
    integer      fd, err, cnt;

    ALU dut (.instruction_i(instruction), .src_A_i(src_A),
             .src_B_i(src_B), .result_o(result));

    // clock
    initial begin
        clk = 0;
        forever #(CYCLE/2) clk = ~clk;
    end

    // reset
    initial begin
        rst = 1;
        #(2*CYCLE) rst = 0;
    end

    // pattern 餵入與比對
    initial begin
        err = 0; cnt = 0;
        fd = $fopen("pattern_alu.csv", "r");
        if (fd == 0) begin $display("open file fail"); $finish; end
        @(negedge rst);
        while (!$feof(fd)) begin
            void'($fscanf(fd, "%h,%h,%h,%h\n",
                          instruction, src_A, src_B, golden));
            #(CYCLE);
            if (result !== golden) begin
                err++;
                $display("[FAIL %0d] inst=%h A=%h B=%h got=%h exp=%h",
                         cnt, instruction, src_A, src_B, result, golden);
            end
            cnt++;
        end
        if (err == 0) $display("=== ALL %0d PATTERNS PASS ===", cnt);
        else          $display("=== %0d / %0d ERRORS ===", err, cnt);
        $fclose(fd);
        $finish;
    end

    // 波形
    initial begin
`ifdef FSDB
        $fsdbDumpfile("alu.fsdb");
        $fsdbDumpvars(0, ALU_tb);
`endif
    end
endmodule
```

## 題 9：觀念題可能考法（簡答 / 除錯）

1. **`always @*` vs `always_comb` 差異**（02a p.30）：
   - `always_comb` 在 time 0 自動執行一次；`@*` 要等訊號變化
   - `always_comb` 的 LHS 不可被其他 process 寫；`@*` 可以
   - `always_comb` 不可含 event control / fork-join / `#delay`
   - `always_comb` 對 function「內容」敏感；`@*` 只對 function「參數」敏感
2. **找出會合成 latch 的程式碼**：case 少 default、if 少 else、輸出沒有先給預設值。
3. **blocking / non-blocking 誤用除錯**：時序區塊用 `=` 造成 race、組合區塊用 `<=`。
4. **Moore vs Mealy**：Moore 輸出只看狀態、在 clock edge 改變、較安全；Mealy 輸出看狀態+輸入、狀態數較少、同 cycle 反應較快但有 glitch 風險。
5. **狀態編碼**：Binary（FF 最少、解碼複雜）、One-hot（FF=N、next-state 邏輯最簡單、適合 FPGA/高速）、Gray（相鄰只變 1 bit、省功耗、適合 CDC）。
6. **4-state**：x = 未初始化/多驅動/未知；z = 高阻抗（bus/三態）。`logic` 與 `reg` 同型別，2-state（bit/int）模擬快但看不到 x。
7. **enum 當狀態**的注意：預設 base 是 `int`（2-state），建議寫 `enum logic [2:0] {...}` 才能在 gate-level 模擬比對 x。
